# mobile-screen-watch

座り過ぎ防止のための作業・休憩タイマーを備えた、モバイル端末向けの24時間表示クロック


## 主な機能

- 24時間制の時計表示(時刻・日付・曜日)
- 作業/休憩タイマー(開始・一時停止・再開・終了)
- 焼き付き防止のための表示ブロック移動(DVDロゴ風のスクリーンセーバー演出)
- 深夜表示(1:00〜7:00は暗い配色で表示)
- ダーク/ライトテーマ切り替え
- PWA対応(オフラインでの時計・タイマー利用、ホーム画面への追加)

## 技術スタック

- Vue 3 + TypeScript
- Vite
- Vitest(ユニットテスト / ブラウザテスト)

## セットアップ

```sh
npm install
npm run dev
```

## スクリプト

| コマンド               | 内容                             |
| ---------------------- | -------------------------------- |
| `npm run dev`           | 開発サーバーを起動               |
| `npm run build`         | 型チェック後に本番ビルド         |
| `npm run preview`       | ビルド結果をプレビュー           |
| `npm run test`          | Vitestをウォッチモードで実行     |
| `npm run test:run`      | Vitestを一度だけ実行             |
| `npm run test:browser`  | ブラウザ環境でのテストを実行     |
| `npm run format`        | Prettierでフォーマット           |
| `npm run format:check`  | フォーマットの確認のみ実行       |
